на верхнем экране - 3D-сцена из файлов игры (Тёмный портал, родные места рас) с персонажем, на нижнем - те же кнопки для

  - glue.txt (пишут ui.bat / convert.bat / all.bat) - скопировать в sdmc:/3ds/w3dproto/: тексты игры, одежда новых

    будет тёмный фон и персонаж без сцены.
В логе: строки "glue scene ..." (камера, место персонажа), "glue: N strings, N start outfits, N zone names".
Если какая-то картинка экранов не найдена в клиенте, на её месте простая рамка (с -v в логе: "ui: ... missing").
Управление: крестовина и A - по экрану; на создании X - случайная внешность, Y - имя, START - создать, B - назад;
на выборе персонажа A - войти, X - создать, Y - удалить, SELECT - сменить мир, B - назад.

=== ВСЁ СРАЗУ С ОБЩИМ ПУЛОМ (этап 5.27) - all.bat или галочка EVERYTHING в w3dgui.exe ===
all.bat [Data] [папка]  =  w3dconv.exe --data <Data> --all -o <папка>
Одним запуском: интерфейс (ui.w3dp) и тексты, звук (папка sound), КАЖДАЯ карта и подземелье из Map.dbc, существа,
игроки с бронёй и оружием, корабли. Получается:
  map0.w3dp      Восточные королевства       map1.w3dp   Калимдор
  map<ID>.w3dp   подземелья, рейды, поля боя (ID карты из Map.dbc)
  common.w3dp    ОБЩИЙ ПУЛ: все текстуры и модели всех карт, каждая один раз (+ common1.w3dp, common2.w3dp ... -
                 части меньше 3.9 ГБ для FAT32)
В map*.w3dp только тайлы (рельеф, вода, полы/стены, расстановка). Здание или текстура, нужная десяти картам,
лежит на диске один раз - в этом экономия. На скорость игры не влияет: консоль читает запись прямо из нужного
файла, держа открытыми все части.
ВСЕ map*.w3dp и common*.w3dp одного запуска связаны (номер сборки внутри): нельзя смешивать файлы двух запусков -
консоль скажет "is from another conversion" и не откроет карту. После новой конвертации копируйте всё заново.
Пропускаются тестовые карты разработчиков (13, 25, 29, 42, 169, 451); --maps 0,1,36 - только перечисленные карты.
Опции: --no-ui, --no-sound-step (без интерфейса / звука), --pool-part-mb N (размер части пула, по умолчанию 3900),
а также обычные --no-items, --gameobjects, --tex-quality ... Проверка: w3dconv.exe --info map0.w3dp (читает и пул).
Превью тоже понимает пул: w3dpreview.exe all\map0.w3dp preview
Прежние convert.bat / test.w3dp работают как раньше (один самостоятельный пак). Если на карте лежат и map0.w3dp, и
test.w3dp, консоль берёт map0.w3dp.

=== w3dgui.exe - ВСЕ КОНВЕРТЕРЫ В ОДНОМ ОКНЕ (проще всего) ===
Запустите w3dgui.exe (рядом должен лежать w3dconv.exe). Укажите папку Data клиента 1.12 и ОДНУ папку для результата,
отметьте что нужно (мир целиком или регион тайлов, существа, игроки, броня, корабли, интерфейс, звук) и нажмите "Запустить".
Шаги идут по очереди: интерфейс и тексты -> звук -> мир. В папке результата получится всё для консоли:
test.w3dp, ui.w3dp, папка sound\, spells/factions/talents/taxi/locks/emotes/transports .txt и журналы log_*.txt.
Всё это (кроме журналов) копируется в sdmc:/3ds/w3dproto/ на SD-карте. Можно сразу выбрать папку <SD>:\3ds\w3dproto.
Весь мир - это часы работы и много места; пак больше 4 ГБ не запишется (предел FAT32). Пути лучше без русских букв.
Окно (интерфейс на английском) сделано без проверки на живой Windows: если что-то не так, пользуйтесь прежними .bat-файлами ниже.
w3dconv.exe --world - то же из командной строки (все тайлы карты).
Галочка "Visibility of the capitals (PVS...)" (6.54e): после паков w3dgui запускает w3docc.exe (он должен лежать рядом)
и считает видимость столиц: Штормград, Стальгорн, Подгород (map0 / test.w3dp) и Оргриммар, Громовой Утёс, Дарнас (map1).
Рядом с паком появятся map0.pvs / map1.pvs (или test.pvs) и отчёты *.pvs.txt - копируйте .pvs на SD вместе с паками,
консоль сама их найдёт. Столицы, которых нет в паке (сконвертирован регион тайлов), пропускаются. Около 30 минут
(зависит от числа ядер). Если шаг конвертации упал, PVS не считается. Отдельно то же делают pvs_stormwind.bat / pvs_cities.bat.
Галочка "Horizon meshes" (6.57, включена по умолчанию): после паков w3docc.exe --hlod строит "горизонт" - для каждого
квадрата 133x133 ярда одну упрощённую модель его зданий и больших деревьев (map0.hlod / map1.hlod / test.hlod рядом с паком,
отчёт *.hlod.txt). 3DS рисует её вместо настоящих зданий дальше 160 ярдов (pad.txt: hlod 160, 0 - выключить) и за дальностью
прорисовки до горизонта (Settings -> Horizon). Копируйте .hlod на SD вместе с паками. Отдельно то же делает horizon.bat.

Инструменты wow3ds для Windows
==============================

Все .bat написаны только латиницей и с переводами строк Windows (CRLF): cmd.exe неправильно
разбирает .bat в UTF-8 с русским текстом и выполняет обрывки строк («'review.exe' is not recognized»).

convert.bat      конвертация региона 30..34 x 46..50 в test.w3dp (+ превью в папке preview).
                 В первой строке set "DATA=..." - путь к папке Data клиента 1.12.
                 Опции w3dconv (дописать в строку w3dconv.exe в convert.bat):
                   --no-wmo              без зданий
                   --wmo-exterior-only   без внутренних помещений
                   --no-floors           без полов и стен (COLL)
                   --no-walls            только полы, сквозь стены можно ходить
                   --no-doodad-coll      без коллизии доодадов (заборы, стволы, мосты-модели)
                   --doodad-coll-tris N  бюджет треугольников коллизии на модель доодада (96)
                   --tex-quality medium  прежнее качество сжатия текстур ETC1 (примерно в 15 раз
                                         медленнее, разница ~0.3 дБ); по умолчанию low
                 Переменная W3D_THREADS=N - число потоков сжатия (по умолчанию все ядра).
                   без --creatures       без существ;  без --players - без моделей игроков
                   --no-items            игроки без экипировки (броня на теле, шлемы, наплечники, оружие);
                   --item-tris N         бюджет треугольников модели предмета (300),  --item-tex N - размер её текстуры (128)
                   --transports          модели кораблей и цеппелинов + transports.txt (пути из TaxiPathNode.dbc, палубы);
                                         --transport-filter ключи - по каким словам в пути модели искать (transport,zeppelin,ship,boat)
                 transports.txt лежит рядом с паком (как taxi.txt) - скопировать в sdmc:/3ds/w3dproto/. Пересобрать пак нужно и для
                 полёта грифонов (анимация Fly сохраняется в моделях существ).
                 Экипировка (пак версии 5) - в логе строка items:. Старый пак клиент не примет: нужен новый convert.bat.
                 Превью брони: w3dpreview.exe test.w3dp preview --player 1 0 0 0 4 7 2 --equip 4=7101,7=7002
                 (слот=ID из ItemDisplayInfo; слоты: 0 голова, 3 рубашка, 4 грудь, 5 пояс, 6 ноги, 7 ступни,
                 8 наручи, 9 перчатки, 14 спина, 18 табард).
                 Пришлите: log_region.txt, preview\region.png, preview\coll_32_48.png,
                 пару preview\creature_*.png и preview\player_*.png.

walk_test.bat    персонаж 60 с ходит по маршруту ~10 ярдов (смотреть вторым клиентом).
fight_test.bat   чат + автоатака + добыча: встаньте рядом с волком на ровном месте; персонаж
                 идёт к мобу по прямой на постоянной высоте. Пришлите fight_log.txt,
                 fight_replay.txt, fight.w3dl.
login_test.bat   только вход на сервер и список персонажей.

Пароль вводится в окне и нигде не сохраняется (в .w3dl его нет).

ИНТЕРФЕЙС (UI, этап 7): ui.bat
  Создаёт ui\ui.w3dp из ВАШЕГО клиента: иконки заклинаний и предметов, рамки окон и кнопки, монеты,
  шрифт FRIZQT (кириллица — из Arial Windows), карты зон и континентов; плюс spells.txt, factions.txt,
  talents.txt, taxi.txt, locks.txt (замки: травы, руда,
  сундуки). Всё скопировать в sdmc:/3ds/w3dproto/. Без ui.w3dp 3DS рисует свой
  простой скин (встроенный шрифт, плоские рамки, буквы вместо иконок).
  Параметры: --ui-skin ui_skin.txt (свой список спрайтов), --ui-font F, --ui-font-fallback F,
  --ui-font-small F, --ui-font-sizes 9 12 16, --ui-icon 40, --ui-map-width 384, --ui-no-maps.

ЗВУК: sound.bat
  Создаёт папку sound\ из ВАШЕГО клиента: звуки интерфейса и событий (sfx.w3ds — щелчки, вкладки,
  окна NPC, монеты, задания, уровень, шёпот, выбор цели), музыку зон (MP3 клиента как есть, папка
  music\), фоновые звуки местности (ambience, .ima) и сетку зон areas_<карта>.bin (по ней 3DS знает,
  в какой зоне персонаж). Папку sound\ целиком скопировать в sdmc:/3ds/w3dproto/sound/.
  Путь к Data — в строке set "DATA=..." (как в ui.bat) или первым аргументом: sound.bat "D:\WoW\Data".
  Звуки мира (world.w3ds + sounds.txt): удары оружия по цели, крики раненых и умирающих существ, агро,
  звуки заклинаний (подготовка, произнесение, попадание), шаги персонажа. Звучат в объёме: слева/справа
  и тише с расстоянием. В логе строки "CreatureSoundData ... column N" и "spells: kit sound column N" —
  какие столбцы таблиц конвертер нашёл сам; -1 значит не нашёл (пришлите лог).
  Занимает несколько сотен МБ (в основном музыка); --no-music / --no-ambience / --no-areas /
  --no-world-sounds — без них; --sound-variants N — сколько вариантов каждого звука мира брать (2).
  --sound-events F — свой список "событие ИмяИзSoundEntries ..." (если в логе что-то "not in this client").
  На 3DS для звука нужен дамп DSP-прошивки sdmc:/3ds/dspfirm.cdc (программа DSP1, один раз).
  Без папки sound\ играют встроенные простые звуки интерфейса; громкость: Настройки ->
  Графика/звук (Музыка, Эффекты, Окружение).

АНИМАЦИИ (игроки, NPC, мобы): нужно ПЕРЕСОБРАТЬ test.w3dp через convert.bat (формат пака v4:
  старый пак 3DS не откроет и попросит перезапустить конвертер). Теперь у моделей сохраняются все
  анимации, которые воспроизводит 3DS: стойка, ходьба/бег, ходьба назад, шаги вбок, плавание (во все
  стороны), прыжок/падение/приземление, стойка в бою по оружию (без оружия, 1H, 2H, древковое, лук,
  ружьё, метательное), удары (в т.ч. левой рукой), ранение/крит, уклонение/парирование/блок, оглушение,
  каст (подготовка с направлением на цель или вокруг себя, выпуск, канал), выстрел из лука/ружья,
  бросок, смерть, сидеть/лежать/стоять на колене (с переходами), стулья, эмоции (/dance, /wave, ...),
  работа NPC (кузнецы, торговцы — по их EMOTESTATE), добыча, езда на маунте (маунт рисуется под
  игроком, всадник — в седле по точке крепления модели маунта).
  Бюджет памяти: --creature-anim-kb N (320 КБ на модель существа) и --player-anim-kb N (900 КБ на
  модель расы); лишние анимации отбрасываются с конца списка приоритетов (в логе: "(N over budget)").
  emotes.txt (из Emotes.dbc) пишут ui.bat и convert.bat — скопировать в sdmc:/3ds/w3dproto/.
  На 3DS: Чат -> Фразы -> Эмоции (помахать, поклон, танец, сесть/встать, лечь ...) или /dance /wave
  /bow /sit /stand /sleep ... в строке чата. При ходьбе сидящий персонаж сам встаёт.

               --no-wmo-water    без воды зданий
В логе: строки "liquids:" и "liquid 0 texture XTextures\river\lake_a.1.blp: ... mean rgb ... -> Light.dbc tint".

море, оранжевый - лава, зелёный - слизь; темнее - глубокая вода (усталость), штрих - вода зданий).

=== ДВИЖУЩИЕСЯ ТЕКСТУРЫ И ПОРТАЛЫ ЗДАНИЙ (этапы 6.41 и 6.42) ===
После обновления конвертер нужно запустить заново (convert.bat / all.bat): без этого пак не содержит новых данных.
* 6.41. Лава, водопады, порталы (в т.ч. на экране выбора персонажа), руны: текстуры моделей теперь движутся (сдвиг/поворот UV из M2).

  Модели существ и надетые предметы пока не анимируются.
* 6.42. Порталы WMO: в каждую группу здания записываются двери в соседние комнаты, и 3DS рисует внутренние комнаты только тогда,
  когда до них дошёл обход через двери от камеры. Опция w3dconv --no-portals выключает. В логе: "portals (6.42): N portal sides in M groups";
  в --info: "WMO portals (6.42): N groups hold M portals".
* 6.43. Т-поза у виверн / грифонов у распорядителя полётов и у прочих NPC в позах (лежит, на коленях, сидит): загрузчик WoWee читал
  диапазоны ключей анимаций 1.12 на один ключ короче, и поза из одного ключа пропадала целиком. Конвертер теперь перечитывает
  треки костей сам. В логе: "M2 key ranges (6.43): N bone tracks of 1.12 models read again". Нужно пересобрать существ (convert.bat / all.bat).
* 6.45. Грифоны на насестах у распорядителя полётов Штормграда и виверны Оргриммара - это не существа, а части декораций-насестов
  (GryphonRoost01, WyvernRoost01) со своим скелетом. Раньше они стояли в позе привязки (крылья раскинуты, "Т-поза"); теперь декорации
  со скелетом ставятся в позу первого кадра своей стойки. В логе: "posed doodads (6.45): N models ...". Нужно пересобрать пак (all.bat).
